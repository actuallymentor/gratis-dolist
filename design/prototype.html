Thesis

Retrieval should drive layout

Todoist nails capture and filtering, then stops. In Sift a view is a saved recipe. Board, list, calendar and widget are just different renderers of the same recipe, and every recipe is editable text.

source→lanes (each a filter)→sort→group→render: board · list · calendar · widget

Capture in under 2 seconds

Widgets, global hotkey, share sheet, email-in. Everything lands in Inbox unless the text says otherwise.

One grammar

Quick-add shorthand, filter queries and recipes share syntax. #home @call p1 means the same thing everywhere.

Views are data

Plain-text recipes you can copy, paste, diff, version and share. No setting lives only in a UI toggle.

Lanes can cascade

First match wins, so Today, Week, Month and Quarter form horizons instead of duplicates. Overlap is one switch away.

Two dates

Scheduled is when I plan to do it. Deadline is when it must be done. Filters can address either or both.

Presets are recipes

Ship opinionated defaults, but each one opens as an editable recipe. Simple by default, deep on demand.

Keys and thumbs

Every action has a keyboard shortcut on desktop and a gesture on mobile.

Local-first

Capture works offline, always. Sync is a background concern, never a spinner.

Research plan

Six tracks; the first five run in parallel

R1

Landscape teardown

Todoist, TickTick, Things, OmniFocus perspectives, Linear views, Amazing Marvin strategies, Taskwarrior urgency, Obsidian Tasks and Dataview. Output: feature matrix and a list of ideas to borrow.

R2

Grammar

One syntax for capture and filters. Decide on Todoist compatibility. Test against 50 real tasks from your account.

R3

Platform capabilities

iOS interactive widgets (App Intents), Android Glance, Tauri global hotkey, PWA share target. Can a widget take text inline, or must it open a sheet?

R4

Sync and stack

Local-first engines (Zero, PowerSync, ElectricSQL, Automerge, Yjs) against offline capture, conflicts, web plus native, self-hosting.

R5

Extensibility tiers

Recipes, then computed fields, then sandboxed plugins, then API and webhooks. Which tiers ship in v1?

R6

Validate

Use this page: mark what you want, then dogfood a clickable build against your real week. Depends on R1–R5.

Visual direction

      
Two looks, same bones

      
Switch them live with Calm / Ledger in the top bar; the whole page re-skins. Light and dark follow your system, with the moon button as override.

    

  

  

    

      
Calm

      

      
Soft cards, rounded checks, Montserrat headings, Nunito body. Solarized-blue dark mode. Generous rows. For a daily review with coffee.

      

    

    

      
Ledger

      

      
Square edges, one-line rows, monospace metadata, no shadows. About 40% more tasks per screen. For keyboard-heavy triage.
