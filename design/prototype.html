What I heard

Your marks, condensed. Below them is how I read the tensions. Round 1 features you marked nope are gone from this page.

Keep

  • Filter-lane board, editable queries, views as text
  • Two dates, local-first, Todoist import
  • Shorthand, share sheet, desktop hotkey
  • Custom fields, subtasks, dependencies, recurrence
  • Plugins, API and CLI, themes
  • 1×1 add widget, lane widget, capture sheet

Drop

  • Calendar view and calendar overlay
  • Weekly review mode, AI triage
  • Voice capture, watch app, capture-bar widget
  • Capture templates, formula fields
  • Self-hosted sync server

Open

  • Deadline syntax Hard to type on phones. See Capture.
  • Quick-add presentation Too busy. Rebuilt below.
  • Grouping within lanes, urgency score
Cascade: concept yes, toolbar switch no

The idea stays. The switch moved into view settings as "Show each task once", on by default. A setting you flip once a year shouldn't sit on the main screen.

Calm and Ledger both marked want

Read as one look plus a density setting. Compact keeps the structure and drops padding and label text.

No calendar views

Time is expressed through lanes ("Today", "Next 7 days"), not grids. Renderers shrink to board and list.

Plugins and API in, formulas out

Power users get code-level extension. In-app spreadsheet logic was a halfway step that added UI weight.

Philosophy

Common actions easy, uncommon actions possible

Each rung is reachable from the one below through a single quiet door: a menu item, a tab, a "?" marker. Nobody has to climb. No rung shows the machinery of the rung above it.

Rung 0

every user, every day

Rung 5

Plugins, API, CLI. New field types, renderers, automations.

Show results, hide machinery

Lanes show names and counts. Queries appear only inside a lane's editor.

Recognition, not instruction

Quick add shows what it understood after you typed it, not a legend of what you could type.

Controls appear on intent

Lane menus fade in on hover and stay visible on touch screens. One sliders icon per view holds its settings.

One accent, few signals

Priority shows only on the checkbox ring. Deadlines use one red flag. Everything else is muted.

Practical · thumbs first

Syntax you can type with one thumb

Every symbol costs taps on a phone keyboard: switch layer, tap the key, switch back. Plain words cost no switches. Rule: words for what's common, cheap prefixes for the rest, and an accessory key for the one expensive character worth keeping.
